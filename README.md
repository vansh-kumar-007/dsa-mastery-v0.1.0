# DSA Mastery — Interactive Python Data Structures & Algorithms Platform (V0.1)

**DSA Mastery** is an interactive, zero-cost (`₹0/month` infrastructure target) web application for learning **Data Structures and Algorithms in Python** from beginner foundations to interview-ready mastery.

## Quick Start
```bash
npm install
npm run dev      # Start Vite dev server
npm run build    # Production bundle into dist/
python3 tests/verify_v01.py  # Run automated algorithm & runner verification
```

## Architecture & Key Links
- **Frontend**: [React](https://react.dev/), [TypeScript](https://vite.dev/guide/), [Tailwind CSS](https://tailwindcss.com/docs)
- **Visual System**: Inspired by [React Bits](https://reactbits.dev/) ([Spotlight Card](https://reactbits.dev/components/spotlight-card), [Shiny Text](https://reactbits.dev/text-animations/shiny-text), [Tilted Card](https://reactbits.dev/components/tilted-card))
- **Python Runtime**: [Pyodide WebAssembly](https://pyodide.org/en/stable/usage/quickstart.html) + Built-In Deterministic Python Subset Interpreter
- **Free Hosting Targets**: [Cloudflare Pages](https://developers.cloudflare.com/pages/platform/limits/) and [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)

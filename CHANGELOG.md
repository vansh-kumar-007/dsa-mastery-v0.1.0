# CHANGELOG.md

## [v0.1.0] — 2026-10-20 (Initial Public Release — V0.1 MVP)
- **Added**: React Bits-inspired developer interface (`SpotlightCard`, `ShinyText`, `DecryptedText`, `TiltedCard`, `AnimatedGridBackground`) with Dark/Light themes and Reduced Motion accessibility toggle.
- **Added**: 6-Module Python DSA Curriculum Roadmap with prerequisite tracking, XP, streak counter, and JSON export/import persistence.
- **Added**: 6 Interactive Python Lessons with Big-O complexity tables, step-by-step dry-run memory traces, and checkpoint quizzes.
- **Added**: Step-by-Step Algorithm Visualizer for **Bubble Sort**, **Insertion Sort**, **Selection Sort**, **Quick Sort**, **Binary Search**, and **Binary Tree / Graph Traversal (BFS & DFS)**.
- **Added**: Interactive Python Coding Workspace & Practice Library with 8 original DSA problems, difficulty/pattern filters, hints, [LeetCode](https://leetcode.com/) references, and dual-engine in-browser Python test evaluation ([Pyodide WASM](https://pyodide.org/en/stable/usage/quickstart.html) + deterministic Python subset interpreter).
